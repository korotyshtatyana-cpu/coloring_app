# Техническая спецификация SVG контуров для Coloring PRO

Этот документ содержит требования к формату SVG-файлов для их корректной работы в приложении "Раскраска PRO".

## 1. Общие требования
- **Формат хранения:** Файлы в Supabase Storage (бакет `countours_svgs`).
- **Корневой тег:** Должен содержать `viewBox`.
- **Очистка:** Удаляйте метаданные редакторов (теги `<metadata>`, `<!-- comments -->`).
- **Стили:** Свойства должны быть прописаны как атрибуты тегов (например, `stroke`, `stroke-width`).

## 2. Обязательная структура XML

### Корневой тег `<svg>`
Должен содержать:
- `viewBox="0 0 width height"` — определяет масштаб холста.

### Теги контура
Приложение поддерживает динамическое изменение **цвета** и **прозрачности** всего контура целиком. 
- **Толщина линий:** Используется оригинальная толщина, заданная в SVG. Приложение больше не модифицирует атрибут `stroke-width` программно, чтобы сохранить авторский стиль контура.
- **Цвет:** Любой цвет в SVG будет перекрыт пользовательским цветом контура (через `BlendMode.srcIn`). Рекомендуется использовать `stroke="#000000"` как стандарт.

## 3. Рекомендованный формат
```xml
<svg viewBox="0 0 500 500" xmlns="http://www.w3.org/2000/svg">
  <path 
    d="..." 
    fill="none" 
    stroke="#000000" 
    stroke-width="2.0" 
    stroke-linecap="round" 
    stroke-linejoin="round" 
  />
</svg>
```

## 4. Инструкция для AI (Промпт для подготовки)

> "Преобразуй SVG код для мобильного приложения: 
> 1. Удали метаданные и лишние теги. 
> 2. Перенеси стили в атрибуты.
> 3. Установи fill='none' для контурных линий.
> 4. Сохрани оригинальные значения stroke-width.
> 5. Оставь только viewBox и xmlns в корне."
