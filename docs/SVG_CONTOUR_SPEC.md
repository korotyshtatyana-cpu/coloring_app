# Техническая спецификация SVG контуров для Coloring PRO

Этот документ содержит требования к формату SVG-кода для его корректной работы в приложении "Раскраска PRO". Приложение динамически управляет цветом, прозрачностью и толщиной линий контура, поэтому код должен быть строго типизирован.

## 1. Общие требования
- **Формат хранения:** Чистый XML-текст (UTF-8).
- **Корневой тег:** Должен содержать `viewBox` и `xmlns`.
- **Метаданные:** Никаких метаданных от Adobe Illustrator, Inkscape или Figma (удаляйте теги `<metadata>`, `<defs>`, `<!-- comments -->`).
- **Стили:** Избегайте использования тега `<style>` и CSS-классов. Все свойства должны быть прописаны как атрибуты тегов `<path>`.

## 2. Обязательная структура XML

### Корневой тег `<svg>`
Должен содержать:
- `viewBox="0 0 width height"` — определяет систему координат.
- `xmlns="http://www.w3.org/2000/svg"` — стандартное пространство имен.

### Теги контура `<path>`
Все линии должны быть представлены тегом `<path>`.
Обязательные атрибуты для каждого пути:
1. `fill="none"` — чтобы внутренние области не перекрывали рисунок пользователя.
2. `stroke="#000000"` — базовый цвет (черный). Приложение ищет этот атрибут для замены на пользовательский цвет.
3. `stroke-width="2.0"` — базовая толщина. Приложение ищет это число для масштабирования.
4. `stroke-linecap="round"` и `stroke-linejoin="round"` — для плавных стыков (рекомендуется).

## 3. Пример кода

### Плохо (код из графического редактора):
```xml
<svg version="1.1" id="Layer_1" xmlns="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink" x="0px" y="0px" width="500px" height="500px" viewBox="0 0 500 500" style="enable-background:new 0 0 500 500;" xml:space="preserve">
<style type="text/css">
	.st0{fill:none;stroke:#000000;stroke-width:2;stroke-miterlimit:10;}
</style>
<path class="st0" d="M100,100c50,0,50,50,100,50s50-50,100-50"/>
</svg>
```

### Хорошо (формат для Coloring PRO):
```xml
<svg viewBox="0 0 500 500" xmlns="http://www.w3.org/2000/svg">
  <path 
    d="M100,100c50,0,50,50,100,50s50-50,100-50" 
    fill="none" 
    stroke="#000000" 
    stroke-width="2.0" 
    stroke-linecap="round" 
    stroke-linejoin="round" 
  />
</svg>
```

## 4. Инструкция для AI (Промпт для преобразования)

Если вы используете другой AI для подготовки контура, скопируйте это сообщение:

> "Преобразуй приложенный SVG код в упрощенный формат для мобильного приложения по рисованию. 
> 1. Удали все метаданные, теги <style>, <defs>, классы и id. 
> 2. Перенеси все стили напрямую в атрибуты тегов <path>.
> 3. Установи для всех путей: fill='none', stroke='#000000', stroke-width='2.0', stroke-linecap='round', stroke-linejoin='round'.
> 4. Убедись, что в корневом теге <svg> есть только атрибут viewBox и xmlns. 
> 5. Верни только чистый XML код."
