# UI спецификация

## Общие принципы
- Адаптивный дизайн (телефоны и планшеты)
- Тёмная и светлая тема
- Минималистичный интерфейс с фокусом на контент
- Использование стандартных паттернов графических редакторов

---

## 1. Экран загрузки (SplashScreen)

### Назначение
Автоматическая авторизация пользователя и переход в приложение.

### UI элементы
- **Центр:** Название приложения "Раскраска PRO" (крупный шрифт)
- **Низ:** CircularProgressIndicator (индикатор загрузки)

### Логика
1. При запуске проверяется авторизация через Google Play / App Store аккаунт
2. Если пользователь авторизован → переход в GalleryScreen
3. Если нет → автоматическая авторизация через аккаунт магазина приложений
4. В случае ошибки → показ диалога с предложением повторить

### Состояния
- `initial` — начальное состояние, показывается логотип
- `loading` — проверка авторизации, показывается индикатор
- `authenticated` — переход в GalleryScreen
- `unauthenticated` — попытка авторизации
- `error` — показ ошибки

## 2. Экран галереи (GalleryScreen)

### Назначение
Просмотр и выбор контуров для раскрашивания.

### UI элементы

**Верхняя панель:**
- Заголовок: "Раскраски"
- Аватар пользователя (справа)

**Фильтры (горизонтальный скролл):**
- "Все" — все доступные контуры
- "⭐ Избранное" — контуры, отмеченные звездой
- "📂 В работе" — начатые проекты

**Сетка контуров:**
- 2 колонки на телефонах
- 3-4 колонки на планшетах
- Бесконечный скролл (пагинация по 20 элементов)
- Pull-to-Refresh для обновления

**Карточка контура:**
- Превью изображение (аспект 1:1)
- Название контура под картинкой
- Иконка звезды (⭐) — активна если в избранном
- Индикатор "В работе" (маленькая иконка 📂) если проект начат

### Логика
1. При открытии загружаются контуры с фильтром "Все"
2. При скролле вниз подгружаются следующие страницы
3. При выборе фильтра список обновляется
4. При нажатии на звезду — добавляется/удаляется из избранного
5. При нажатии на карточку:
    - Если проект не начат → переход в CanvasScreen с новым контуром
    - Если проект начат → переход в CanvasScreen с сохраненным проектом

### Состояния
- `initial` — начальное состояние
- `loading` — загрузка контуров
- `success` — контуры загружены
- `failure` — ошибка загрузки
- `hasReachedMax` — все контуры загружены

## 3. Экран холста (CanvasScreen)

### Назначение
Раскрашивание контура с профессиональными инструментами.

### UI элементы

**Холст:**
- Полноэкранный
- Верхний слой — векторный контур (недоступен для редактирования)
- Нижний слой — рисунок пользователя
- Поддержка мультитач (зум, панорамирование)

**Верхняя панель (плавающая):**
- Кнопка "Назад" (←) — возврат в галерею с автосохранением
- Кнопка "Экспорт" (📤) — открывает меню экспорта
- Индикатор автосохранения (зелёная точка/галочка)

**Левая панель (вертикальная):**
- Ползунок "Размер кисти" (вертикальный, 1-100px)
- Ползунок "Прозрачность" (вертикальный, 0-100%)
- Кнопка "Сброс вида" (🔄) — возврат к исходному масштабу и центру

**Нижняя панель (инструменты):**
- 🎨 Цвет — открывает палитру
- 🖊️ Кисти — открывает выбор кистей
- 🟦 Ластик — стирает только нижний слой
- ↩️ Отмена — отменяет последнее действие (до 5 шагов)
- ↪️ Повтор — возвращает отмененное действие
- 🖼️ Контур — открывает настройки контура

### Логика

**Рисование:**
1. Начало касания → начало мазка
2. Движение пальца/стилуса → добавление точек с учетом:
    - Размера кисти
    - Прозрачности
    - Типа кисти
    - Давления (если поддерживается)
3. Окончание касания → завершение мазка, добавление в историю

**Стилус (давление):**
- Использовать `event.pressure` (0.0-1.0)
- Реальный размер = `baseSize * pressure` (от 1 до baseSize)
- Если давление не поддерживается → используется baseSize

**Мультитач:**
- Два пальца → зум и панорамирование
- Кнопка "Сброс вида" → возврат к исходному состоянию

**Автосохранение:**
- После каждого завершенного мазка (с дебаунсом 500ms)
- При выходе из экрана (нажатие "Назад")
- При переключении приложения в фон

**Отмена/Повтор:**
- Хранится история до 5 последних мазков
- Отмена → мазок перемещается в стек отмены
- Повтор → мазок возвращается из стека отмены

### Состояния
- `initial` — холст загружен
- `drawing` — процесс рисования
- `loading` — загрузка проекта
- `saving` — сохранение проекта
- `error` — ошибка

## 4. Палитра цветов (ColorPicker)

### Назначение
Выбор цвета для кисти или контура.

### UI элементы
- Цветовой круг (HSV) — выбор оттенка
- Ползунки RGB или HSV для точной настройки
- Поле текущего цвета (превью)
- Кнопка "Пипетка" (🧪) — выбор цвета с холста
- Кнопка "Применить" и "Отмена"

### Логика
1. При открытии показывается текущий цвет
2. При выборе цвета на круге — обновляется превью
3. При нажатии "Пипетка" — появляется лупа, увеличивающая область под пальцем
4. При отпускании — цвет считывается и применяется
5. При нажатии "Применить" — цвет сохраняется и палитра закрывается

## 5. Выбор кистей (BrushPicker)

### Назначение
Выбор типа кисти для рисования.

### UI элементы
- Сетка с превью кистей (2-3 колонки)
- Каждая кисть: иконка + название

### Типы кистей
| Тип | Описание |
|-----|----------|
| Круглая | Обычная круглая кисть |
| Квадратная | Кисть с квадратным наконечником |
| Акварель | Размытые края, полупрозрачная |
| Мелок | Зернистая текстура |
| Маркер | Насыщенный цвет, полупрозрачный |
| Каллиграфическая | Зависит от направления движения |
| Текстурная | С текстурой (облако, трава и т.д.) |
| Аэрограф | Размытая, с разбросом точек |

### Логика
1. При выборе кисти — она становится активной
2. При повторном нажатии — закрывается палитра

## 6. Настройки контура (ContourSettings)

### Назначение
Настройка внешнего вида верхнего слоя (контура).

### UI элементы
- Цвет контура — кнопка с превью, открывает ColorPicker
- Прозрачность — горизонтальный слайдер (0-100%)
- Толщина — горизонтальный слайдер (1-10px)
- Кнопка "Сбросить" — возврат к стандартным настройкам
- Кнопка "Применить" и "Отмена"

### Логика
1. При открытии показываются текущие настройки
2. При изменении — контур на холсте обновляется в реальном времени
3. При нажатии "Применить" — настройки сохраняются

## 7. Экспорт (ExportMenu)

### Назначение
Экспорт готовой раскраски.

### UI элементы
- Сохранить в галерею (📷)
- Поделиться через... (📱) — открывает системное меню шаринга

### Логика
1. При выборе "Сохранить в галерею" — склеиваются слои → PNG → сохраняется
2. При выборе "Поделиться через..." — открывается системное меню
3. После экспорта показывается уведомление об успехе/ошибке

3. Настройка сохраняется в SharedPreferences
