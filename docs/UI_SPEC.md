# UI спецификация

## Общие принципы
- Адаптивный дизайн (телефоны и планшеты через `ResponsiveHelper`)
- Минималистичный интерфейс с фокусом на контент
- Использование стандартных паттернов графических редакторов
- Тема: только светлая тема (`lightTheme`); переключатель и тёмная тема удалены

---

## 1. Экран загрузки (SplashScreen)

### Назначение
Автоматическая авторизация пользователя и переход в приложение.

### UI элементы
- **Центр:** анимированный логотип (`AnimatedLogo`): SVG-логотип и брендовый текст с эффектом shimmer
- **При ошибке:** кнопка ручного входа (`LoginButton`) под логотипом

Отдельного спиннера на splash-экране нет: индикатором загрузки служит бесконечная анимация логотипа. Виджеты `SplashTitle` и `SplashStatusIndicator` существуют в модуле, но в текущем `SplashContent` не используются.

### Логика
1. При запуске проверяется текущая авторизация (`CheckAuth`).
2. Если пользователь авторизован → переход в `GalleryRoute` после завершения вступительной анимации.
3. Если нет → выполняется автоматический вход через уже авторизованный аккаунт Google Play / App Store (`SignInSilently`).
4. При каждом успешном входе данные пользователя автоматически синхронизируются с таблицей `users` на стороне базы данных (через DB Trigger).
5. Если автоматический вход недоступен или отменён → отображается кнопка ручного входа (`LoginButton`), которая запускает `SignIn`.
6. Кнопка ручного входа показывается **только** при `AuthStatus.failure`.
7. Ошибки показываются через `ErrorDialog`; отмена входа и недоступность silent sign-in не считаются ошибкой.

### Состояния
- `initial` — начальное состояние, показывается логотип
- `loading` — проверка или выполнение авторизации, продолжается анимация логотипа
- `success` + `isAuthenticated = true` — переход в `GalleryRoute`
- `failure` — показ кнопки ручного входа

## 2. Экран галереи (GalleryScreen)

### Назначение
Просмотр и выбор контуров для раскрашивания.

### UI элементы

**Верхняя панель:**
- Заголовок: локализованный `LocaleKeys.gallery`; в dev-сборке рядом показывается номер сборки
- Справа — кнопка-аватар пользователя (`UserAvatarButton`), открывающая `SettingsRoute`
- Цвет рамки аватара отражает план: золотой для Premium, фиолетовый для No Ads, нейтральный без подписки

**Фильтры (горизонтальный скролл):**
- "Все" — все доступные контуры
- "Избранное" — контуры, отмеченные звездой
- "В работе" — начатые проекты

**Категории (второй горизонтальный скролл):**
- «Все категории» + Динамический список используемых категорий.
- Отображаются только те категории, в которых есть хотя бы один контур (через `GetUsedCategoriesUseCase`).
- Список категорий определяется enum `ContourCategory`.
- Контур может принадлежать нескольким категориям: при выборе чипа показываются все контуры, в списке `categories` которых есть выбранная категория.

**Сетка контуров:**
- **Телефоны:** 2 колонки (портрет).
- **Планшеты:** 3 колонки (портрет).
- **Ландшафт (все устройства):** 4 колонки.
- Используется `ResponsiveHelper` для определения типа устройства.
- Бесконечный скролл (пагинация по `Constants.pageSize`)
- Pull-to-Refresh для обновления

**Карточка контура:**
- Превью изображение (аспект 1:1): миниатюра начатого проекта, если она есть, иначе превью контура
- Название контура под картинкой
- Иконка звезды (⭐) — активна если в избранном
- Индикатор "В работе" если проект начат
- Бейдж доступа в правом верхнем углу: rewarded (фиолетовый + play), paid (золотой + корона), view-only (нейтральный + глаз), отсутствие бейджа для доступных проектов

**Баннер рекламы:**
- Показывается внизу экрана только при `showAds == true`
- Скрыт для активной подписки и пожизненной покупки No Ads

### Логика
1. При открытии загружаются контуры с фильтром "Все" и список активных категорий.
2. При скролле вниз подгружаются следующие страницы.
3. При выборе фильтра список обновляется.
4. Пагинация применяется ко всем фильтрам.
5. При нажатии на звезду — добавляется/удаляется из избранного.
6. При нажатии на карточку: заблокированный `paid` проект открывает диалог покупки; `rewarded` может запустить Rewarded Video; доступный проект открывается в `CanvasRoute`.
7. Пока грузится rewarded-видео, поверх галереи показывается `AdLoadingOverlay`.
8. Ошибка отображается отдельным `ErrorDialog` с действием повтора.

## 3. Экран холста (CanvasScreen)

### Назначение
Раскрашивание контура с профессиональными инструментами.

### UI элементы

**Холст:**
- Полноэкранный.
- **Многослойная архитектура (Bitmap Baking):**
    - **Белая страница:** отдельный `ColoredBox`.
    - **Завершённые мазки:** кэшированное изображение всех завершённых мазков (`RasterCanvasBuffer`).
    - **Активный мазок:** векторная отрисовка линии в реальном времени (`ActiveStroke`).
    - **Верхний слой:** векторный контур (`ContourLayer`), загружаемый по URL из Supabase Storage.
- `ClipRect` обрезает рисунок по границам страницы.
- Зум и панорамирование выполняются через `InteractiveViewer`; собственные жесты обрабатываются `Listener` (включая мультитач и давление стилуса).

**Верхняя панель (плавающая):**
- Кнопка "Назад" (←) — сохраняет проект с миниатюрой и возвращает в галерею; во время сохранения показывается полноэкранный индикатор.
- Иконка `sync` — индикатор автосохранения при `CanvasStatus.saving`.
- Кнопка "Поделиться" (share) — открывает меню экспорта.
- Кнопка "Информация" (info) — открывает/повторно показывает onboarding холста.

**Левая панель (вертикальная):**
- Переключатель кисти (`BrushButton`) с выбором инструмента.
- Переключатель ластика (`EraserButton`) с выбором инструмента ластика.
- Ползунок "Размер кисти" (1–100px).
- Ползунок "Прозрачность" (0–100%).
- Кнопка "Сброс вида" (сброс зума и панорамирования).
- Кнопка "Сброс проекта" (очистка рисунка).
- На низких экранах элементы раскладываются в две колонки.

**Нижняя панель (справа внизу):**
- ↩️ Отмена — до 5 шагов (`Constants.maxUndoSteps`).
- ↪️ Повтор.
- Кружок текущего цвета кисти — открывает палитру.
- Иконка контура — открывает палитру для цвета и прозрачности контура.

**Режим только просмотра:**
- Левая и нижняя панели затемнены и не принимают нажатия.
- Внизу показывается `ViewOnlyBanner` с причиной (возврат покупки, истёкшая подписка или изначально закрытый проект) и, если контур загружен, кнопкой разблокировки доступа.
- Панорамирование, зум и шаринг остаются доступными.

### Логика

**Загрузка:**
- Проект считается загруженным только после получения данных из БД и успешной компиляции SVG-контура (`isContourReady`).
- Если SVG не загружен (ошибка сети), холст разблокируется для рисования без контура.
- Onboarding показывается при первом открытии холста и повторно по кнопке информации.

**Рисование:**
- Новые точки добавляются только если расстояние от предыдущей > `Constants.minPointDistance` (1.5px).
- При завершении мазка он «запекается» в фоновый битмап для экономии ресурсов.
- Мазок не прерывается на краях страницы, пока указатель не отпущен.

**Ластик:**
- Работает по тем же принципам, что и кисть, но удаляет пользовательские мазки.
- Размер ластика соответствует размеру кисти.

**Отрисовка мазков (`StrokeRenderer` / `ActiveStrokePainter`):**
- Для линий с постоянной шириной используется `canvas.drawPath`.
- Для pressure-sensitive инструментов ширина меняется посегментно через `drawLine`.
- `CanvasPainter` в текущем стеке холста не используется: завершённые мазки рисует `RasterCanvasBuffer`, активный — `ActiveStrokePainter`.

**Автосохранение:**
- После мазка сохранение запускается с задержкой `Constants.autosaveDebounce` (500 мс).
- При уходе приложения в фон выполняется сохранение без перерисовки миниатюры.

**Экспорт:**
- `CanvasRenderingService` скачивает SVG контура при необходимости и рендерит PNG с белым фоном.
- Результат можно сохранить в галерею устройства или отправить через системный share.

### Состояния
- `initial`, `loading`, `ready`, `drawing`, `saving`, `exporting`, `error`.
- При `CanvasStatus.error` индикатор загрузки скрывается, чтобы показать диалог ошибки.

**Поля `CanvasState`:**
- `status`, `strokes`, `currentStroke`, `contour`.
- `undoStack`, `redoStack`.
- `brushSize`, `opacity`, `color`, `brushType`, `isEraser`.
- `contourColor`, `contourOpacity`, `contourSize`, `contourSvg`, `isContourReady`.
- `transform`, `exportedFilePath`, `lastExportType`, `thumbnailPath`, `error`.
- `availableTools`, `activeBrushId`, `activeEraserId`.
- `isViewOnly`, `viewOnlyReason`.

## 4. Палитра цветов (ColorPickerDialog)

### Логика
1. Поддерживает выбор цвета как для кисти, так и для контура (флаг `isContour`).
2. Кнопка "Пипетка" позволяет захватить цвет с любой точки холста.

---

## 5. Настройки контура

Настройки контура открываются из нижней панели тем же `ColorPickerDialog` с флагом `isContour: true`.

### UI элементы
- **Цвет контура** — выбор через палитру (Hue, насыщенность, яркость) или пипетку.
- **Прозрачность** — горизонтальный слайдер.
- **Толщина** — настройки нет: используется оригинальная толщина линий из SVG.

---

## 6. Меню экспорта (ExportMenu)

### Логика
1. `CanvasRenderingService` скачивает XML контура (если его нет в памяти) и склеивает его с битмапом мазков.
2. Сохранение/шаринг в формате PNG.
