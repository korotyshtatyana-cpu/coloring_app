# UI спецификация

## Общие принципы
- Адаптивный дизайн (телефоны и планшеты через `ResponsiveHelper`)
- Минималистичный интерфейс с фокусом на контент
- Использование стандартных паттернов графических редакторов
- Тема: только светлая тема (`lightTheme`); переключатель и тёмная тема удалены

---

## 1. Экран загрузки (SplashScreen)

### Назначение
Автоматическая авторизация пользователя и переход в приложение.

### UI элементы
- **Центр:** Название приложения "Раскраска PRO" (крупный шрифт)
- **Низ:** `CircularProgressIndicator` (индикатор загрузки)
- **При ошибке:** кнопка ручного входа (`LoginButton`)

### Логика
1. При запуске проверяется текущая авторизация (`CheckAuth`).
2. Если пользователь авторизован → переход в `GalleryScreen`.
3. Если нет → выполняется автоматический вход через уже авторизованный аккаунт Google Play / App Store (`SignInSilently`).
4. При каждом успешном входе данные пользователя автоматически синхронизируются с таблицей `users` на стороне базы данных (через DB Trigger).
5. Если автоматический вход недоступен или отменён → отображается кнопка ручного входа (`LoginButton`), которая запускает `SignIn`.
6. Кнопка ручного входа показывается **только** при `AuthStatus.failure`.
7. В случае ошибки → обработка через `ErrorHandler`.

### Состояния
- `initial` — начальное состояние, показывается логотип
- `loading` — проверка или выполнение авторизации, показывается индикатор
- `success` + `isAuthenticated = true` — переход в `GalleryScreen`
- `failure` — показ кнопки ручного входа

## 2. Экран галереи (GalleryScreen)

### Назначение
Просмотр и выбор контуров для раскрашивания.

### UI элементы

**Верхняя панель:**
- Заголовок: "Раскраски"
- Кнопка настроек (справа)

**Фильтры (горизонтальный скролл):**
- "Все" — все доступные контуры
- "Избранное" — контуры, отмеченные звездой
- "В работе" — начатые проекты

**Категории (второй горизонтальный скролл):**
- «Все категории» + Динамический список используемых категорий.
- Отображаются только те категории, в которых есть хотя бы один контур (через `GetUsedCategoriesUseCase`).
- Список категорий определяется enum `ContourCategory`.

**Сетка контуров:**
- **Телефоны:** 2 колонки (портрет).
- **Планшеты:** 3 колонки (портрет).
- **Ландшафт (все устройства):** 4 колонки.
- Используется `ResponsiveHelper` для определения типа устройства.
- Бесконечный скролл (пагинация по `Constants.pageSize`)
- Pull-to-Refresh для обновления

**Карточка контура:**
- Превью изображение (аспект 1:1)
- Название контура под картинкой
- Иконка звезды (⭐) — активна если в избранном
- Индикатор "В работе" если проект начат

### Логика
1. При открытии загружаются контуры с фильтром "Все" и список активных категорий.
2. При скролле вниз подгружаются следующие страницы.
3. При выборе фильтра список обновляется.
4. Пагинация применяется ко всем фильтрам.
5. При нажатии на звезду — добавляется/удаляется из избранного.
6. При нажатии на карточку: переход в `CanvasScreen`.
7. Ошибка отображается отдельным `ErrorDialog`.

## 3. Экран холста (CanvasScreen)

### Назначение
Раскрашивание контура с профессиональными инструментами.

### UI элементы

**Холст:**
- Полноэкранный.
- **Многослойная архитектура (Bitmap Baking):**
    - **Нижний слой:** Кэшированное изображение всех завершенных мазков (`RasterCanvasBuffer`).
    - **Слой рисования:** Векторная отрисовка активного мазка в реальном времени.
    - **Верхний слой:** Векторный контур (`ContourLayer`), загружаемый из Supabase Storage.
- Поддержка мультитач (зум, панорамирование) через `InteractiveViewer`.

**Верхняя панель (плавающая):**
- Кнопка "Назад" (←) — возврат в галерею с автосохранением.
- Кнопка "Экспорт" (📤) — открывает меню экспорта.
- Индикатор автосохранения при `CanvasStatus.saving`.

**Левая панель (вертикальная):**
- Ползунок "Размер кисти" (1-100px).
- Ползунок "Прозрачность" (0-100%).
- Кнопка "Сброс вида" (🔄).

**Нижняя панель (инструменты):**
- 🎨 Цвет — открывает палитру.
- 🖊️ Кисти — открывает выбор кистей.
- 🟦 Ластик — стирает пользовательские мазки (размер ластика соответствует размеру кисти).
- ↩️ Отмена — до 5 шагов.
- ↪️ Повтор.
- 🖼️ Контур — открывает настройки контура (цвет, прозрачность).

### Логика

**Загрузка:**
- Проект считается загруженным только после получения данных из БД и успешной компиляции SVG-контура (`isContourReady`).
- Если SVG не загружен (ошибка сети), холст разблокируется для рисования без контура.

**Рисование:**
- Новые точки добавляются только если расстояние от предыдущей > `Constants.minPointDistance` (1.5px).
- При завершении мазка он «запекается» в фоновый битмап для экономии ресурсов.

**Ластик:**
- Работает по тем же принципам, что и кисть, но рисует белым цветом.
- Размер ластика идентичен размеру кисти (без множителей).

**CanvasPainter:**
- Использует `drawPath` для оптимизации отрисовки линий с постоянной шириной.

### Состояния
- `initial`, `loading`, `ready`, `drawing`, `saving`, `exporting`, `error`.
- При `CanvasStatus.error` индикатор загрузки скрывается, чтобы показать диалог ошибки.

**Поля `CanvasState`:**
- `status`, `strokes`, `currentStroke`, `contour`, `contourSvg`, `isContourReady`, `undoStack`, `redoStack`.
- `brushSize`, `opacity`, `color`, `brushType`, `isEraser`.
- `contourColor`, `contourOpacity`.
- `transform`, `error`.

## 4. Палитра цветов (ColorPickerDialog)

### Логика
1. Поддерживает выбор цвета как для кисти, так и для контура (флаг `isContour`).
2. Кнопка "Пипетка" позволяет захватить цвет с любой точки холста.

---

## 5. Настройки контура (ContourSettings)

### UI элементы
- **Цвет контура** — выбор через `ColorPicker`.
- **Прозрачность** — горизонтальный слайдер.
- **Толщина** — настройка удалена, используется оригинальная толщина из SVG.

---

## 6. Меню экспорта (ExportMenu)

### Логика
1. `CanvasRenderingService` скачивает XML контура (если его нет в памяти) и склеивает его с битмапом мазков.
2. Сохранение/шаринг в формате PNG.
