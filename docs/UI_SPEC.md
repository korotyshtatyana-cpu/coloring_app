# UI спецификация

## Общие принципы
- Адаптивный дизайн (телефоны и планшеты)
- Минималистичный интерфейс с фокусом на контент
- Использование стандартных паттернов графических редакторов
- Тема: только светлая тема (`lightTheme`); переключатель и тёмная тема удалены

---

## 1. Экран загрузки (SplashScreen)

### Назначение
Автоматическая авторизация пользователя и переход в приложение.

### UI элементы
- **Центр:** Название приложения "Раскраска PRO" (крупный шрифт)
- **Низ:** `CircularProgressIndicator` (индикатор загрузки)
- **При ошибке:** кнопка ручного входа (`LoginButton`)

### Логика
1. При запуске проверяется текущая авторизация (`CheckAuth`).
2. Если пользователь авторизован → переход в `GalleryScreen`.
3. Если нет → выполняется автоматический вход через уже авторизованный аккаунт Google Play / App Store (`SignInSilently`).
4. При каждом успешном входе данные пользователя автоматически синхронизируются с таблицей `users` на стороне базы данных (через DB Trigger).
5. Если автоматический вход недоступен или отменён → отображается кнопка ручного входа (`LoginButton`), которая запускает `SignIn`.
6. Кнопка ручного входа показывается **только** при `AuthStatus.failure`.
7. В случае ошибки → обработка через `ErrorHandler`.

### Состояния
- `initial` — начальное состояние, показывается логотип
- `loading` — проверка или выполнение авторизации, показывается индикатор
- `success` + `isAuthenticated = true` — переход в `GalleryScreen`
- `failure` — показ кнопки ручного входа

## 2. Экран галереи (GalleryScreen)

### Назначение
Просмотр и выбор контуров для раскрашивания.

### UI элементы

**Верхняя панель:**
- Заголовок: "Раскраски"
- Кнопка настроек (справа)

**Фильтры (горизонтальный скролл):**
- "Все" — все доступные контуры
- "Избранное" — контуры, отмеченные звездой
- "В работе" — начатые проекты

**Категории (второй горизонтальный скролл):**
- «Все категории» + Животные, Природа, Фэнтези, Мандалы, Транспорт, Города, Люди, Цветы, Узоры, Абстракция
- Список категорий определяется enum `ContourCategory` (`domain/lib/src/entities/contour_category.dart`).
- `ContourCategory.all` означает «Все категории» и не хранится в базе данных.
- Use cases конвертируют `ContourCategory.all` в `null` перед запросом к репозиторию.
- Локализация названий выполняется через `ContourCategoryLocalization.localized()` в `features/gallery/lib/src/extensions/contour_category_extension.dart`.

**Сетка контуров:**
- 2 колонки на телефонах
- 3-4 колонки на планшетах
- Бесконечный скролл (пагинация по `Constants.pageSize`)
- Pull-to-Refresh для обновления

**Карточка контура:**
- Превью изображение (аспект 1:1)
- Название контура под картинкой
- Иконка звезды (⭐) — активна если в избранном
- Индикатор "В работе" если проект начат

### Логика
1. При открытии загружаются контуры с фильтром "Все"
2. При скролле вниз подгружаются следующие страницы
3. При выборе фильтра список обновляется
4. Пагинация применяется ко всем фильтрам, включая "Избранное" и "В работе" (через `GetContoursByIdsUseCase`)
5. При нажатии на звезду — добавляется/удаляется из избранного
6. При нажатии на карточку:
    - Если проект не начат → переход в CanvasScreen с новым контуром
    - Если проект начат → переход в CanvasScreen с сохраненным проектом
7. Ошибка отображается отдельным `ErrorDialog`, а не виджетом внутри списка

### Состояния
- `initial` — начальное состояние
- `loading` — загрузка контуров
- `success` — контуры загружены
- `failure` — ошибка загрузки
- `hasReachedMax` — все контуры загружены

## 3. Экран холста (CanvasScreen)

### Назначение
Раскрашивание контура с профессиональными инструментами.

### UI элементы

**Холст:**
- Полноэкранный
- Нижний слой — рисунок пользователя (CustomPainter)
- Верхний слой — векторный контур через `SvgPicture.string` (недоступен для редактирования)
- Поддержка мультитач (зум, панорамирование) через `InteractiveViewer`

**Верхняя панель (плавающая):**
- Кнопка "Назад" (←) — возврат в галерею с автосохранением
- Кнопка "Экспорт" (📤) — открывает меню экспорта
- Индикатор автосохранения (зелёная иконка) при `CanvasStatus.saving`

**Левая панель (вертикальная):**
- Ползунок "Размер кисти" (вертикальный, 1-100px)
- Ползунок "Прозрачность" (вертикальный, 0-100%)
- Кнопка "Сброс вида" (🔄) — возврат к исходному масштабу и центру

**Нижняя панель (инструменты):**
- 🎨 Цвет — открывает палитру
- 🖊️ Кисти — открывает выбор кистей
- 🟦 Ластик — стирает только нижний слой
- ↩️ Отмена — отменяет последнее действие (до 5 шагов)
- ↪️ Повтор — возвращает отмененное действие
- 🖼️ Контур — открывает настройки контура

### Логика

**Рисование:**
1. Начало касания → начало мазка
2. Движение пальца/стилуса → добавление точек с учетом:
    - Размера кисти
    - Прозрачности
    - Типа кисти
    - Давления (если поддерживается)
3. Окончание касания → завершение мазка, добавление в историю

**Обработка касаний:**
- Используется `Listener` с `onPointerDown`, `onPointerMove`, `onPointerUp`, `onPointerCancel`
- `event.pressure` передаётся в BLoC

**Стилус (давление):**
- Использовать `event.pressure` (0.0-1.0)
- Реальный размер = `max(minBrushSize, baseSize * pressure)`
- Если давление не поддерживается → используется baseSize

**Мультитач:**
- `InteractiveViewer` → зум и панорамирование
- Кнопка "Сброс вида" → возврат к исходному состоянию

**Автосохранение:**
- После каждого завершенного мазка (с дебаунсом `Constants.autosaveDebounce`)
- При выходе из экрана (нажатие "Назад")
- При переключении приложения в фон (`AppLifecycleState.paused/inactive`)

**Отмена/Повтор:**
- Реализованы в `CanvasBloc` через `undoStack`/`redoStack`
- Ограничены `Constants.maxUndoSteps` шагами
- Отмена → мазок перемещается в стек отмены
- Повтор → мазок возвращается из стека отмены

**CanvasPainter:**
- Рисует белый фон и мазки (нижний слой)
- Контур отрисовывается отдельным `SvgPicture.string` поверх, с применением настройки толщины

### Состояния
- `initial` — холст загружен
- `loading` — загрузка проекта
- `ready` — готов к рисованию
- `drawing` — процесс рисования
- `saving` — сохранение проекта
- `exporting` — экспорт изображения
- `error` — ошибка

**Поля `CanvasState`:**
- `status`, `strokes`, `currentStroke`, `contour`, `undoStack`, `redoStack`
- `brushSize`, `opacity`, `color`, `brushType`, `isEraser`
- `contourColor`, `contourOpacity`, `contourWidth`
- `transform`, `error`

## 4. Палитра цветов (ColorPickerDialog)

### Назначение
Выбор цвета для кисти.

### UI элементы
- Цветовой круг (HSV) — выбор оттенка
- Ползунки RGB/HSV для точной настройки
- Поле текущего цвета (превью)
- Кнопка "Пипетка" (`LocaleKeys.eyedropper`)
- Кнопка "Сохранить"

### Пакет
- `flutter_colorpicker: ^1.1.0`

### Логика
1. При открытии показывается текущий цвет кисти
2. При выборе цвета на круге — обновляется превью и сразу применяется в BLoC
3. При нажатии "Пипетка" — закрывается диалог и активируется режим пипетки на холсте
4. При нажатии "Сохранить" — диалог закрывается

## 5. Выбор кистей (BrushPicker)

### Назначение
Выбор типа кисти для рисования.

### UI элементы
- Сетка с превью кистей (3 колонки)
- Каждая кисть: иконка-заглушка + название

### Типы кистей
| Тип | Иконка-заглушка |
|-----|-----------------|
| Круглая | `Icons.circle_outlined` |
| Квадратная | `Icons.square_outlined` |
| Акварель | `Icons.water_drop_outlined` |
| Мелок | `Icons.grain` |
| Маркер | `Icons.edit` |
| Каллиграфическая | `Icons.brush` |
| Текстурная | `Icons.texture` |
| Аэрограф | `Icons.cloud` |

### Логика
1. При выборе кисти — она становится активной
2. Активная кисть выделяется цветом фона

## 6. Настройки контура (ContourSettings)

### Назначение
Настройка внешнего вида верхнего слоя (контура).

### UI элементы
- **Цвет контура** — кнопка с превью, открывает `ColorPicker`
- **Прозрачность** — горизонтальный слайдер (0-100%)
- **Толщина** — горизонтальный слайдер (`minContourWidth` - `maxContourWidth`)
- Кнопка "Сохранить"

### Локализационные ключи
- `contour`, `contour_color`, `opacity`, `brush_size`, `save`

### Логика
1. При открытии показываются текущие настройки
2. При изменении — контур на холсте обновляется в реальном времени
3. При нажатии "Сохранить" — настройки сохраняются

## 7. Меню экспорта (ExportMenu)

### Назначение
Экспорт готовой раскраски.

### UI элементы
- Поделиться (📤) — `LocaleKeys.share`
- Сохранить в галерею (📷) — `LocaleKeys.save_to_gallery`

### Логика
1. Экспорт запускается через `CanvasBloc` событием `ExportImage(ExportType)`
2. `ExportImageUseCase` + `CanvasRepository.exportImage` склеивают белый фон, мазки и контур, сохраняют в PNG
3. При выборе "Поделиться" — вызывается `ShareFileUseCase`
4. При выборе "Сохранить в галерею" — вызывается `SaveImageToGalleryUseCase`
5. После экспорта показывается уведомление об успехе/ошибке

## 8. Экран настроек (SettingsScreen)

### Назначение
Настройки приложения.

### UI элементы
- **Язык** — выпадающий список (Dropdown)
    - English (en)
    - Русский (ru)

### Логика
1. При открытии показывается текущий язык
2. При выборе языка — локаль переключается через `context.setLocale`
3. Настройка сохраняется в `SharedPreferences` через `UpdateSettingsUseCase`

### Удалено
- Переключатель тёмной темы (`ThemeSwitch`) удалён из проекта
- Тёмная тема не поддерживается
