# Приложение "Раскраска PRO"

## Общее описание
Мобильное приложение для раскрашивания векторных контуров с профессиональными инструментами рисования. Поддерживает планшеты и телефоны, стилусы с определением силы нажатия, многослойность и облачное хранение контуров.

## Платформы
- Android (минимальная версия: API 21)
- iOS (минимальная версия: 13.0)

## Целевые устройства
- Смартфоны (портретная ориентация)
- Планшеты (портретная и ландшафтная ориентация)

## Ключевые особенности
1. Автоматическая авторизация через Google Play / App Store аккаунт
2. Галерея векторных контуров с фильтрацией (Все, Избранное, В работе, Категории)
3. Двухслойный холст (верхний слой - контур, нижний - рисунок пользователя)
4. Профессиональные инструменты: кисти с текстурами, настройка размера и прозрачности
5. Поддержка силы нажатия стилуса (Apple Pencil / S Pen)
6. Пипетка с лупой для точного выбора цвета
7. Отмена/повтор действий (5 шагов)
8. Автосохранение проектов
9. Экспорт в PNG и шаринг
10. Полноценная палитра цветов (цветовой круг + RGB/HSV ползунки)

## Технический стек
- **Фреймворк:** Flutter 3.16+
- **Язык:** Dart 3.2+
- **Архитектура:** Clean Architecture (Presentation → Domain → Data)
- **State Management:** BLoC (с единым состоянием)
- **DI:** get_it (appLocator)
- **Локализация:** easy_localization (с генерацией константных ключей)
- **Навигация:** auto_route (с автогенерацией)
- **База данных:** Drift (SQLite) — современный ORM с генерацией кода
- **Облачная БД:** Supabase (контуры, избранное, проекты)
- **Авторизация:** google_sign_in, sign_in_with_apple
- **Флейворы:** dev, prod (через main_dev.dart и main_prod.dart)
- **Логирование:** logger (AppLogger)

## Структура проекта
```
coloring_app/
├── core/ # Ядро (локализация, темы, утилиты, конфиг, DI)
├── core_ui/ # UI компоненты (только виджеты, без DI)
├── domain/ # Общий домен (интерфейсы репозиториев, usecases, DI)
├── data/ # Общие данные (реализации репозиториев, DI)
├── navigation/ # Навигация (auto_route, DI)
├── features/ # Фичи (auth, gallery, canvas, settings)
├── lib/ # Точка входа (main_common, main_dev, main_prod, app.dart)
├── docs/ # Документация (для AI-агента)
└── pubspec.yaml
```


## Требования к коду
- **Длина строки:** 100 символов
- **Разбивка по файлам:** Каждый класс в отдельном файле
- **Разделение UI и логики:** Весь бизнес-код вынесен из виджетов
- **Best Practices:** Следование официальным рекомендациям Flutter
- **Именование:**
    - Папки: snake_case
    - Файлы: snake_case
    - Классы: PascalCase
    - Переменные/методы: camelCase
    - Константы: UPPER_SNAKE_CASE
- **Документация:** Все публичные методы и классы должны иметь dartdoc комментарии

## Флейворы
- **dev:** Для разработки (использует .env.dev)
- **prod:** Для продакшена (использует .env.prod)

## Локальное хранилище и синхронизация
Используем Drift для работы с SQLite и Supabase для облачного хранения:
- **Локально (Drift):** мгновенное сохранение каждого мазка (таблицы `projects`, `strokes`).
- **Облако (Supabase):** синхронизация полного состояния проекта (JSON) при закрытии экрана или сворачивании приложения.
- **Преимущества:** высокая производительность (60 FPS при рисовании) и сохранность данных в облаке.

## Экспорт модулей
Каждый модуль экспортирует только то, что будет использоваться в других модулях.
- `core` → экспортирует: темы, утилиты, локализацию, AppConfig, AppLogger, DI
- `core_ui` → экспортирует: переиспользуемые виджеты (только UI)
- `domain` → экспортирует: интерфейсы репозиториев, usecases, модели, DI
- `data` → экспортирует: реализации репозиториев, Drift базу, DI
- `navigation` → экспортирует: роутер, маршруты, DI
- `features/*` → экспортирует: BLoC, экраны

## Обработка ошибок
Используется единый механизм обработки ошибок:
- `ErrorHandler` — централизованная обработка
- `ErrorMessages` — локализованные сообщения об ошибках
- `ErrorReporting` — репортинг ошибок (опционально)
- `AppErrorHandlerProvider` — провайдер для перехвата ошибок
