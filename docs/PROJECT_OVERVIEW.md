# Приложение "Раскраска PRO"

## Общее описание
Мобильное приложение для раскрашивания векторных контуров с профессиональными инструментами рисования. Поддерживает планшеты и телефоны, стилусы с определением силы нажатия, многослойность и облачное хранение контуров.

## Платформы
- Android (минимальная версия: API 21)
- iOS (минимальная версия: 13.0)

## Целевые устройства
- Смартфоны (портретная ориентация)
- Планшеты (портретная и ландшафтная ориентация)

## Ключевые особенности
1. Автоматическая авторизация через Google Play / App Store аккаунт
2. Галерея векторных контуров с фильтрацией и обновлением миниатюр проектов (Все, Избранное, В работе, Категории)
3. Двухслойный холст (верхний слой — контур через SVG, нижний — рисунок пользователя) с поддержкой поворота и плавного сглаживания контура
4. Профессиональные инструменты: кисти с текстурами, настройка размера и прозрачности, удобное переключение между кистью и ластиком
5. Поддержка силы нажатия стилуса (Apple Pencil / S Pen) с динамическим размером мазка
6. Пипетка для выбора цвета с холста
7. Интеллектуальная отмена/повтор действий (полное сохранение мазков в истории)
8. Автосохранение проектов и настроек контура
9. Экспорт в PNG: поделиться или сохранить в галерею устройства (белый фон + рисунок + контур)
10. Полноценная палитра цветов в формате оверлея с выбором оттенка (Hue), насыщенности и яркости
11. Настройка контура в формате оверлея: цвет, прозрачность (с градиентом), толщина

## Технический стек
- **Фреймворк:** Flutter 3.44+
- **Язык:** Dart 3.12+
- **Архитектура:** Clean Architecture (Presentation → Domain → Data)
- **State Management:** BLoC (с единым состоянием)
- **DI:** get_it (appLocator)
- **Локализация:** easy_localization (с генерацией константных ключей)
- **Навигация:** auto_route (с автогенерацией)
- **База данных:** Drift (SQLite) — современный ORM с генерацией кода
- **Облачная БД:** Supabase (контуры, избранное, проекты)
- **Авторизация:** google_sign_in, sign_in_with_apple
- **Флейворы:** dev, prod (через main_dev.dart и main_prod.dart)
- **Логирование:** logger (AppLogger)
- **Экспорт:** share_plus, image_gallery_saver

## Требования к коду
Полный список стандартов кодирования и лучших практик доступен в документе **[GOOD_PRACTICES.md](GOOD_PRACTICES.md)**.

Основные правила:
- **Длина строки:** 100 символов
- **Разбивка по файлам:** Каждый класс в отдельном файле
- **Разделение UI и логики:** Весь бизнес-код вынесен из виджетов. Оптимизация перерисовок через `context.select`.
- **Best Practices:** Использование `const`, запрет на методы `_build...()`.
- **Именование:**
    - Папки: snake_case
    - Файлы: snake_case
    - Классы: PascalCase
    - Переменные/методы: camelCase
    - Константы: UPPER_SNAKE_CASE
- **Документация:** Все публичные методы и классы должны иметь dartdoc комментарии

## Флейворы

- **prod:** Для продакшена (использует .env.prod)

## Локальное хранилище и синхронизация
Используем Drift для работы с SQLite и Supabase для облачного хранения:
- **Локально (Drift):** мгновенное сохранение каждого мазка (таблицы `Projects`, `Strokes`) и кэширование контуров (`Contours`).
- **Облако (Supabase):** синхронизация полного состояния проекта (JSON) при сохранении/автосохранении.
- **Преимущества:** высокая производительность (60 FPS при рисовании) и сохранность данных в облаке.

## Экспорт модулей
Каждый модуль — Dart package с собственным `pubspec.yaml`. Экспортируется только то, что используется в других модулях.
- `core` → экспортирует: утилиты, локализацию, AppConfig, AppLogger, DI, а также `flutter_dotenv` и `easy_localization`
- `core_ui` → экспортирует: переиспользуемые виджеты и светлую тему
- `domain` → экспортирует: интерфейсы репозиториев, usecases, модели, DI
- `data` → экспортирует: реализации репозиториев, провайдеры, сервисы, DI
- `navigation` → экспортирует: `auto_route`, `AppRouter`, `NavigationDI`
- `features/*` → экспортирует: только сгенерированные классы маршрутов (`*Route`)

## Обработка ошибок
Используется единый механизм обработки ошибок:
- `ErrorHandler` — централизованная обработка, инициализируется с `GlobalKey<NavigatorState>` и показывает `ErrorDialog` через `overlay?.context`
- `ErrorMessages` — локализованные сообщения об ошибках
- `ErrorReporting` — репортинг ошибок
- `AppErrorHandlerProvider` — провайдер для перехвата ошибок `FlutterError.onError` и `Bloc.observer`

## Навигация
Корневой `AppRouter` находится в модуле `navigation`. Маршруты определены в порядке:
1. Splash (initial)
2. Canvas
3. Gallery
4. Settings
